# 解决方案顾问 Agent

输入客户情况，自动完成「需求解析 → 方案设计 → 厂商选型 → 投行级财务测算 → 风险对策」五步推理链，输出一份**参数可回溯、算法可复算**的智慧建筑方案建议书。

在线演示：**https://ccru1995.github.io/solution-agent/**

纯静态单页 + 一个纯逻辑内核，零依赖、零后端、零密钥——不配置任何 API 也能完整使用。

## 核心能力

**推理链（透明可审计）**
1. 需求解析 — 由建筑类型与目标推导必选模块，每个判断给依据
2. 方案设计 — 三档配置；超预算时按「单位投资节能效率」自动裁剪，地基模块不砍
3. 厂商选型 — 六维评分（权重归一）+ 场景亲和加成 + 差距归因
4. 财务测算 — 完整 DCF：CAPM 推导 WACC、逐年自由现金流、NPV / IRR / MIRR / 双回收期 / PI / ROIC−WACC 利差 / ±20% 敏感性 / Gordon 终值（含边界防护）/ 碳减排
5. 风险对策 — 分级风险库按区域与配置触发

**专业口径**
- 多模块合成节能率用 `1 − Π(1−xᵢ)`（边际递减），而非简单相加导致高估
- 终值仅在 WACC 显著高于永续增长率时计入，避免误导性巨值
- MIRR 以 WACC 为再投资率，比 IRR 保守

**反事实分析**
逐个移除模块计算 NPV 损失，给出「预算不足先砍谁」的量化答案——这是顾问被压价时的核心论据。

**干系人视角**
CFO / CTO / 业主 / 运维总监四类角色，各自会问什么、怎么回应。

## 与常见"AI 套壳 Demo"的区别

| 常见 Demo | 本项目 |
|---|---|
| 调一次 LLM 返回一段话 | 五步推理链，每步展示推理依据与模型口径 |
| 数字是模型编的 | 财务数字来自内置 DCF 引擎，可用 Node 复算 |
| 无可解释性 | 权重向量归一公示、差距归因、证据分级 |
| 一套方案 | 保守 / 平衡 / 激进三方案并排，自动判定最优投资强度 |
| 不能被压价 | 反事实分析：预算不足时按性价比排序砍模块 |
| 忽略风险 | 按区域自动触发合规风险（Saudization / 信创 / EPBD） |

**AI 润色（可选）**
可在设置里填自己的 LLM 接口，浏览器直连服务商润色执行摘要；密钥仅存本机 localStorage，不经任何中间服务器。**不配置时全部功能照常可用**（本地引擎生成完整提案）。

## 本地运行

双击 `index.html` 即可；或：

```bash
npx serve .
```

## 运行测试

内核与页面均有测试（57 项断言），jsdom 直接驱动真实页面验证渲染与交互：

```bash
npm i jsdom   # 或复用已有的全局 jsdom
node test/agent-core.test.js
```

## 边界与声明

- 能耗基准、厂商评分、电价与排放因子为同类项目基准与模型假设，用于方案沟通；正式投资决策需以现场能耗审计数据替换。
- 厂商评分为公开定位的主观量化，可按实际尽调调整权重与分值。
- AI 润色为可选项，生成内容应经人工复核。
